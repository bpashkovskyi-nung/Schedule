# НУНГ Розклад — Release Notes

## Версія 1.0 (build 1)

### Нове

- Оновлено Android-застосунок із двома основними сторінками: «Розклад» і «Налаштування».
- Додано вибір розкладу для групи, викладача або аудиторії з відповідними факультетами, кафедрами та корпусами.
- Додано введення періоду у форматі `dd.MM.yyyy`.
- Додано налаштування «Приховувати минулі дати».
- Додано налаштування «Отримувати сповіщення про нові пари».
  Застосунок перевіряє розклад приблизно раз на годину у фоновому режимі та відновлює перевірку після перезавантаження телефона.
- Налаштування вибраного об’єкта, періоду та сповіщень зберігаються на пристрої.
- Додано нову іконку календаря з розкладом.
- Назву застосунку змінено на «НУНГ Розклад».
- Android package id: `com.schedule.nung`.
- Production API: `https://api.schedule.ksm.if.ua/`.

### Виправлення

- Прибрано порожні заняття без опису з розкладу та iCal-експорту.
- Виправлено відображення dropdown-списків і відмінки українських підписів.
- Зайві підписи та номери на сторінці розкладу прибрано.
- Legacy-сайт переведено на GET-запити для коректного повторення сторінки через F5.
- iCal генерується з JSON-розкладу без прямого використання зламаного експорту деканату.

### Артефакти

- `.apk` — для встановлення на Android-пристрій.
- `.aab` — для завантаження в Google Play.
